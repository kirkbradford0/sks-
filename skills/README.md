# SKS Skills Boundary

Executable, personal, machine-specific, credential-adjacent, or operational SKS skills belong in the private `kirkbradford0/sks-skills` vault.

This public repository is the SKS coordination plane only.

## Public-repo rule
Do not commit:
- personal or private user data
- local machine paths or identifiers
- email routing details or private endpoints
- secrets, tokens, credentials, or deployment URLs
- private source corpora

Public files may reference a private skill by name and describe its status at a high level, but should not duplicate its private instructions or supporting files.
